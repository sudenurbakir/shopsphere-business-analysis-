# Change Request Template

## Amaç

Bu doküman, proje kapsamında iletilen değişiklik taleplerinin kayıt altına alınması, değerlendirilmesi ve onay sürecinin takip edilmesi amacıyla hazırlanmıştır.

---

## Değişiklik Talebi

| Alan                 | Açıklama                                   |
| -------------------- | ------------------------------------------ |
| Change ID            | CR-001                                     |
| Talep Tarihi         | YYYY-MM-DD                                 |
| Talep Eden           | İş Birimi / Paydaş                         |
| Başlık               | Değişiklik başlığı                         |
| Açıklama             | Talebin detaylı açıklaması                 |
| Gerekçe              | Değişikliğin yapılma nedeni                |
| Öncelik              | Düşük / Orta / Yüksek                      |
| Etkilenen Modüller   | Ürün, Sepet, Sipariş, Ödeme vb.            |
| Etkilenen Dokümanlar | BRD, SRS, User Story, API, UAT             |
| İş Etkisi            | Beklenen iş değeri veya etkisi             |
| Teknik Etki          | API, Veritabanı, UI vb. üzerindeki etkiler |
| Tahmini Efor         | X İnsan/Gün                                |
| Karar                | Onaylandı / Reddedildi / Beklemede         |
