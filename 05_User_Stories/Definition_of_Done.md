# Definition of Done

## Amaç

Bu doküman, ShopSphere E-Ticaret Sipariş ve Ödeme Yönetim Sistemi projesinde bir User Story'nin "Tamamlandı (Done)" olarak kabul edilebilmesi için karşılaması gereken kriterleri tanımlar.

---

## Definition of Done Kriterleri

Bir User Story aşağıdaki koşulların tamamını sağladığında tamamlanmış kabul edilir:

* İş gereksinimleri karşılanmıştır.
* Acceptance Criteria'nın tamamı sağlanmıştır.
* Geliştirme tamamlanmıştır.
* Kod gözden geçirme (Code Review) tamamlanmıştır.
* Birim testleri (Unit Test) başarıyla tamamlanmıştır.
* İlgili test senaryoları başarıyla geçmiştir.
* Kritik veya yüksek öncelikli hata bulunmamaktadır.
* Dokümantasyon gerekli durumlarda güncellenmiştir.
* Ürün sahibi veya ilgili iş birimi tarafından onaylanmıştır.

---

## Tamamlanma Kontrol Listesi

| Kriter                       | Durum |
| ---------------------------- | ----- |
| Gereksinimler karşılandı     | ☐     |
| Acceptance Criteria sağlandı | ☐     |
| Geliştirme tamamlandı        | ☐     |
| Code Review tamamlandı       | ☐     |
| Unit Test tamamlandı         | ☐     |
| Test senaryoları başarılı    | ☐     |
| Kritik hata bulunmuyor       | ☐     |
| Dokümantasyon güncellendi    | ☐     |
| Onay alındı                  | ☐     |

---

## Not

Definition of Done, geliştirme ekibi, test ekibi ve iş biriminin bir User Story'nin tamamlandığı konusunda ortak bir anlayışa sahip olmasını sağlar. Bu kriterler, proje boyunca geliştirilen tüm User Story'ler için referans olarak kullanılacaktır.
