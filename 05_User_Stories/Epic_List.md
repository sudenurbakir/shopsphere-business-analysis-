# Epic List

## Amaç

Bu doküman, ShopSphere E-Ticaret Sipariş ve Ödeme Yönetim Sistemi kapsamında geliştirilecek ana işlev gruplarını (Epic) tanımlar.

---

| Epic ID  | Epic Adı           | Açıklama                                                                        |
| -------- | ------------------ | ------------------------------------------------------------------------------- |
| EPIC-001 | Kullanıcı Yönetimi | Kullanıcı kayıt, giriş, profil ve hesap yönetimi işlemlerini kapsar.            |
| EPIC-002 | Ürün Yönetimi      | Ürün listeleme, arama, filtreleme ve ürün detay görüntüleme işlemlerini kapsar. |
| EPIC-003 | Alışveriş Sepeti   | Sepete ürün ekleme, çıkarma ve güncelleme işlemlerini kapsar.                   |
| EPIC-004 | Sipariş ve Ödeme   | Checkout, ödeme ve sipariş oluşturma süreçlerini kapsar.                        |
| EPIC-005 | Sipariş Yönetimi   | Sipariş görüntüleme, takip ve iptal işlemlerini kapsar.                         |
| EPIC-006 | İade ve Geri Ödeme | İade talebi oluşturma ve geri ödeme süreçlerini kapsar.                         |
| EPIC-007 | Stok Yönetimi      | Ürün stoklarının takip edilmesi ve güncellenmesini kapsar.                      |
| EPIC-008 | Yönetim Paneli     | Ürün, sipariş, stok ve kullanıcı yönetimi işlemlerini kapsar.                   |
