# User Stories

## Amaç

Bu doküman, ShopSphere E-Ticaret Sipariş ve Ödeme Yönetim Sistemi için kullanıcı ihtiyaçlarını User Story formatında tanımlar.

| ------ | -------------------------------------------------------------------------------------------------- |

| US-002 | **Bir kullanıcı olarak**, sisteme giriş yapmak **istiyorum** ki hesabıma erişebileyim.             |
