# Functional Requirements

## Amaç

Bu doküman, ShopSphere E-Ticaret Sipariş ve Ödeme Yönetim Sistemi'nin sağlaması gereken fonksiyonel gereksinimleri tanımlar.

---

## Kullanıcı Yönetimi

| ID     | Gereksinim                                                               |
| ------ | ------------------------------------------------------------------------ |
| FR-001 | Sistem kullanıcı kayıt işlemini desteklemelidir.                         |
| FR-002 | Kullanıcı sisteme giriş yapabilmelidir.                                  |
| FR-003 | Kullanıcı şifresini sıfırlayabilmelidir.                                 |
| FR-004 | Kullanıcı profil bilgilerini görüntüleyebilmeli ve güncelleyebilmelidir. |

---

## Ürün Yönetimi

| ID     | Gereksinim                                               |
| ------ | -------------------------------------------------------- |
| FR-005 | Kullanıcı ürünleri listeleyebilmelidir.                  |
| FR-006 | Kullanıcı ürünleri kategoriye göre filtreleyebilmelidir. |
| FR-007 | Kullanıcı ürün araması yapabilmelidir.                   |
| FR-008 | Kullanıcı ürün detaylarını görüntüleyebilmelidir.        |

---

## Alışveriş Sepeti

| ID     | Gereksinim                                        |
| ------ | ------------------------------------------------- |
| FR-009 | Kullanıcı ürünü sepete ekleyebilmelidir.          |
| FR-010 | Kullanıcı sepetten ürün çıkarabilmelidir.         |
| FR-011 | Kullanıcı ürün adetini güncelleyebilmelidir.      |
| FR-012 | Sistem sepet toplam tutarını hesaplayabilmelidir. |

---

## Sipariş ve Ödeme

| ID     | Gereksinim                                          |
| ------ | --------------------------------------------------- |
| FR-013 | Kullanıcı teslimat adresi seçebilmelidir.           |
| FR-014 | Kullanıcı ödeme yöntemini seçebilmelidir.           |
| FR-015 | Sistem ödeme işlemini gerçekleştirebilmelidir.      |
| FR-016 | Başarılı ödeme sonrasında sipariş oluşturulmalıdır. |

---

## Sipariş Yönetimi

| ID     | Gereksinim                                                |
| ------ | --------------------------------------------------------- |
| FR-017 | Kullanıcı sipariş geçmişini görüntüleyebilmelidir.        |
| FR-018 | Kullanıcı sipariş detaylarını görüntüleyebilmelidir.      |
| FR-019 | Kullanıcı uygun durumdaki siparişini iptal edebilmelidir. |
| FR-020 | Kullanıcı sipariş durumunu takip edebilmelidir.           |

---

## İade ve Geri Ödeme

| ID     | Gereksinim                                                       |
| ------ | ---------------------------------------------------------------- |
| FR-021 | Kullanıcı iade talebi oluşturabilmelidir.                        |
| FR-022 | Sistem iade talebini kaydetmelidir.                              |
| FR-023 | Sistem onaylanan iadeler için geri ödeme sürecini başlatmalıdır. |

---

## Yönetim Paneli

| ID     | Gereksinim                                      |
| ------ | ----------------------------------------------- |
| FR-024 | Yönetici ürün ekleyebilmelidir.                 |
| FR-025 | Yönetici ürün bilgilerini güncelleyebilmelidir. |
| FR-026 | Yönetici ürün silebilmelidir.                   |
| FR-027 | Yönetici siparişleri görüntüleyebilmelidir.     |
| FR-028 | Yönetici sipariş durumunu güncelleyebilmelidir. |
| FR-029 | Yönetici stok bilgilerini güncelleyebilmelidir. |
| FR-030 | Yönetici kullanıcıları görüntüleyebilmelidir.   |
