# Non-Functional Requirements

## Amaç

Bu doküman, ShopSphere E-Ticaret Sipariş ve Ödeme Yönetim Sistemi'nin performans, güvenlik, kullanılabilirlik ve diğer kalite gereksinimlerini tanımlar.

---

## Performans

| ID      | Gereksinim                                                                           |
| ------- | ------------------------------------------------------------------------------------ |
| NFR-001 | Sistem normal kullanım koşullarında sayfaları en fazla 3 saniye içinde yüklemelidir. |
| NFR-002 | Sistem aynı anda en az 500 aktif kullanıcıyı desteklemelidir.                        |
| NFR-003 | Sipariş ve ödeme işlemleri kesintisiz olarak tamamlanabilmelidir.                    |

---

## Güvenlik

| ID      | Gereksinim                                                                    |
| ------- | ----------------------------------------------------------------------------- |
| NFR-004 | Kullanıcı giriş işlemleri kimlik doğrulama ile korunmalıdır.                  |
| NFR-005 | Kullanıcı şifreleri güvenli şekilde saklanmalıdır.                            |
| NFR-006 | Tüm veri alışverişi güvenli bağlantı (HTTPS) üzerinden gerçekleştirilmelidir. |

---

## Kullanılabilirlik

| ID      | Gereksinim                                                                            |
| ------- | ------------------------------------------------------------------------------------- |
| NFR-007 | Sistem kullanıcı dostu bir arayüze sahip olmalıdır.                                   |
| NFR-008 | Kullanıcılar temel işlemleri ek bir eğitime ihtiyaç duymadan gerçekleştirebilmelidir. |

---

## Güvenilirlik

| ID      | Gereksinim                                                                            |
| ------- | ------------------------------------------------------------------------------------- |
| NFR-009 | Sistem verilerin doğruluğunu korumalıdır.                                             |
| NFR-010 | Beklenmeyen bir hata durumunda kullanıcıya anlaşılır bir hata mesajı gösterilmelidir. |

---

## Uyumluluk

| ID      | Gereksinim                                                                                     |
| ------- | ---------------------------------------------------------------------------------------------- |
| NFR-011 | Sistem güncel web tarayıcılarını desteklemelidir.                                              |
| NFR-012 | Sistem kişisel verilerin korunmasına ilişkin yürürlükteki yasal düzenlemelere uygun olmalıdır. |
