# Business Glossary

## Amaç

Bu doküman, ShopSphere E-Ticaret Sipariş ve Ödeme Yönetim Sistemi projesinde kullanılan temel iş analizi ve teknik terimlerin açıklamalarını içerir.

---

## Terimler

| Terim                  | Açıklama                                                                                             |
| ---------------------- | ---------------------------------------------------------------------------------------------------- |
| API                    | Sistemler arasında veri alışverişi sağlayan uygulama programlama arayüzüdür.                         |
| Acceptance Criteria    | Bir User Story'nin tamamlanmış sayılması için karşılanması gereken koşullardır.                      |
| Authentication         | Kullanıcının kimliğinin doğrulanması işlemidir.                                                      |
| Authorization          | Kimliği doğrulanan kullanıcının erişim yetkilerinin kontrol edilmesidir.                             |
| BPMN                   | İş süreçlerini standart bir gösterim dili ile modellemek için kullanılan notasyondur.                |
| BRD                    | Business Requirements Document. İş gereksinimlerini açıklayan dokümandır.                            |
| CRUD                   | Create, Read, Update, Delete işlemlerini ifade eder.                                                 |
| ER Diagram (ERD)       | Veritabanı tablolarını ve aralarındaki ilişkileri gösteren diyagramdır.                              |
| Epic                   | Aynı iş hedefini destekleyen User Story grubudur.                                                    |
| Functional Requirement | Sistemin gerçekleştirmesi gereken fonksiyonel gereksinimdir.                                         |
| JSON                   | API'lerde veri alışverişi için kullanılan veri formatıdır.                                           |
| NFR                    | Non-Functional Requirement. Performans, güvenlik ve kullanılabilirlik gibi kalite gereksinimleridir. |
| Primary Key (PK)       | Bir tablo içindeki her kaydı benzersiz olarak tanımlayan alandır.                                    |
| Foreign Key (FK)       | Tablolar arasında ilişki kurulmasını sağlayan alandır.                                               |
| SQL                    | Veritabanı işlemleri için kullanılan sorgulama dilidir.                                              |
| SRS                    | Software Requirements Specification. Yazılım gereksinimlerini açıklayan dokümandır.                  |
| Swagger / OpenAPI      | REST API'lerini standart şekilde dokümante etmek için kullanılan spesifikasyondur.                   |
| UAT                    | User Acceptance Testing. Son kullanıcı tarafından gerçekleştirilen kabul testidir.                   |
| User Story             | Kullanıcının sistemden beklediği iş ihtiyacını anlatan gereksinimdir.                                |
| Wireframe              | Bir ekranın yerleşimini gösteren düşük detaylı tasarım taslağıdır.                                   |

---

## Not

Bu sözlük, proje boyunca kullanılan teknik ve iş analizi terimlerinin ortak bir anlamda kullanılmasını sağlamak amacıyla hazırlanmıştır.
